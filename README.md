# React + Vite

## Om prosjektet
Applikasjonen visualiserer geografiske risikodata (spesifikt for Stryn kommune). 
Formålet med appen er å gjøre det enklere å sammenligne risiko i ulike områder. Denne informasjonen kan brukes til å lage en plan for vedlikehold og/eller forebygging av veier. Appen baseres på ArcGIS Maps SDK for JavaScript.

## Teknologi
Prosjektet er utviklet med:
- ArcGIS Maps SDK for JavaScript
- React
- Vite
- JavaScript
- GeoJSON
